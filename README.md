# workout-bot 🏋️

Telegram-бот для тренировок на Java.

## О проекте

Бот помогает тренироваться осознанно. В итоговой версии он будет работать в Telegram и уметь:

- подбирать программу тренировок под цель (набор массы, похудение, сила), место занятий (зал или дом) и число тренировок в неделю;
- считать разовый максимум и рабочие веса по результатам подхода;
- вести дневник тренировок и показывать историю и прогресс;
- напоминать о занятиях.

Проект учебный и развивается поэтапно, поэтому состав возможностей может меняться.

## Текущий этап

**Этап 1: консольная версия.** Подключение к Telegram планируется позже.

Что уже работает:

- **Подбор программы.** Бот в диалоге спрашивает цель, место занятий и число тренировок в неделю (2-5), затем выдаёт расписание по дням недели, схему подходов с повторами и отдыхом и нужный инвентарь. Диалог можно отменить на любом шаге.
- **Расчёт максимума.** По весу и числу повторов (например, 80 кг на 8 раз) бот считает максимум на одно повторение по формуле Эпли и рабочие веса в 90%, 80% и 70% от него.
- **Справка.** Бот приветствует, рассказывает о командах и по запросу описывает каждую подробно.

Актуальный список команд бот показывает сам: введите `/help`.

## Запуск

Нужны JDK 21 и Maven.

```bash
git clone https://github.com/asadbektazhiev/workout-bot.git
cd workout-bot
mvn compile
java -cp target/classes bot.Main
```

Проще всего запустить `Main.java` из IntelliJ IDEA (зелёный треугольник рядом с методом `main`).

Тесты: `mvn test`.

## Рекомендации

- Начните с `/help`: бот сам расскажет, что умеет.
- Если в консоли Windows русский текст отображается некорректно, добавьте VM-опцию `-Dfile.encoding=UTF-8`.
- Если у вас JDK 17, замените `21` на `17` в `pom.xml` (`maven.compiler.source` и `maven.compiler.target`).
- Чтобы добавить команду, реализуйте интерфейс `Command` и зарегистрируйте её в `Bot.createDefault()`. В `/help` она появится сама.
